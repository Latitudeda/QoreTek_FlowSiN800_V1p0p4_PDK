layers.py
==============

The layers are auto-generated by filling the ``layers.csv`` file, ``FLYLINE_MARK`` layer is defined by **Latitudeda** for display.

::

    class LAYER(TECH.LAYER):
        WG = Layer(PROCESS.WG, PURPOSE.DRW, 'Fully etched Si3N4 waveguide')
        HEATER = Layer(PROCESS.HEAT, PURPOSE.DRW, 'Pt heater')
        HEATER_PAD_OPEN = Layer(PROCESS.HPO, PURPOSE.DRW, 'Local opening of heater cladding')
        BBOX = Layer(PROCESS.BBOX, PURPOSE.DRW, 'Bounding box of pre-optimized\r\ndevices')
        BBOX_TXT = Layer(PROCESS.BBOX, PURPOSE.MARK, 'Text description for BBOX device')
        LABEL = Layer(PROCESS.Labeltext, PURPOSE.MARK, 'Text label (for indication only)')
        OPIN = Layer(PROCESS.Labeltext, PURPOSE.DRW1, 'Optical port pin (for indication only)')
        EPIN = Layer(PROCESS.Labeltext, PURPOSE.DRW2, 'Electrical port pin (for indication only)')
        DESIGN = Layer(PROCESS.DA, PURPOSE.MARK, 'Design area')
        FLYLINE_MARK = Layer(PROCESS.FLYLINE, PURPOSE.MARK1, 'Flyline for insufficient space in AutoLink')


For users using layout viewers (e.g. KLayout), they can import the layer properties file ``layers.lyp`` in ``technology/generated`` file folder.
